## 🔎 Configuração de Sitemap no Search Console

1. Acesse o Google Search Console
    
2. Procure pelo domínio que você cadastrou
    
3. Clique sobre ele
    
4. Na janela que aparecer, selecione **"Ir para a propriedade"**
    

---

### 📄 Enviar o Sitemap

1. No menu lateral esquerdo, clique em **Sitemaps**
    
2. No campo de envio, digite:
    

```bash
sitemap.xml
```

3. Clique em **Enviar**
    

---

> ⚠️ **Importante**  
> Na primeira tentativa, pode aparecer um erro.  
> Isso é **normal**.

👉 Basta enviar novamente:

```bash
sitemap.xml
```

Após isso, o status deve aparecer como **Processado**.

---

### ✅ Validação final

- Acesse o site do cliente
    
- Verifique se tudo está funcionando normalmente
